How every video is made

Built like an engineering report, told like a story

Sourced first

Every date, number and name is checked against primary sources — official reports, papers, court records — and listed on the video's page.

Animated from code

Every frame is drawn in code with the open-source ManimGL engine, so each idea is shown from first principles, not stock footage.

Made to explore

Each story ends with names, papers and questions to follow up, and an interactive lab where you can run the idea yourself.
